Kill switch

How it works

Every Active client whose Next Invoice Date has passed automatically becomes Past Due. Their dashboard shows a locked screen.

To reinstate: record payment → edit client → set status to Active + update invoice date.

-- Auto-run daily via pg_cron:
select cron.schedule(
  'kill-switch',
  '0 9 * * *',
  'select run_kill_switch()'
);
